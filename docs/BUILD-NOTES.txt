빌드 환경 이슈
- 이 Windows 환경의 Godot에서 .bat 도구 실행 실패가 발생함.
- APK는 Godot unsigned export 후 Java apksigner.jar로 서명.
- AAB는 Godot이 생성한 Android assets를 사용해 Java GradleWrapperMain으로 빌드 후 jarsigner로 서명.
- 웹 빌드는 실제 모바일 크기의 Edge에서 로딩·터치 이동·집기 확인, 브라우저 오류 0개.
- Windows 배포 실행본도 --headless -- --smoke-test 실행 완료.
- Android 에뮬레이터 검증 상세는 별도 인수인계 문서에 기록.

범위
- Play Store 업로드는 사용자 담당. 계정/심사/스토어 등록정보 제출은 진행하지 않음.
- 현재는 프로토타입이며 결제·광고·성과 추적 SDK·채용 지원 랜딩은 미포함.
- 기존 HTML 코드의 자동 변환이 아니라 로직 이식 작업이며, 이후 Godot 소스는 웹/앱을 함께 빌드 가능.
